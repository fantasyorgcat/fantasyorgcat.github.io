## 固定欄位成品

預設球員欄 160px、場次 64px、每個統計欄 88px、Rank 98px。整個數據表固定 1202px，**不依球隊、內容、統計期間或視窗寬度重新分配欄寬**。桌面 1327px / 1500px 可直接看到全部數據；手機沿用相同格式，以橫向捲動及「跳至 Rank」查看，球員欄與表頭固定。

逐日賽程固定 84px（120px 設計基準的 70%），保留原本球隊賽程表。球員表預設數據優先，可勾選「同時顯示逐日賽程」。日期簡寫為 MM/DD ET，完整日期保留於 title / aria-label，跨年與平台週次計算仍使用原始完整日期。黑體字、固定數字對齊、緊湊列距，保留米／藍／橘／粉配色。

## 排名口徑

- 預設 9CAT：PTS、REB、AST、3PM、STL、BLK、FG%、FT%、TO；保留既有完整統計母體的原始 Rank，不加入 MIN。
- 自訂類別：直接加總網站名單球員既有、未四捨五入的各項 PR，再依總和排名。此排名範圍是網站名單中所選 PR 齊全者，不宣稱為全聯盟母體排名或聯盟 ROTO 積分。搜尋與球隊篩選不改排名。
- 同分並列 1、1、3；缺任一納入 PR 時不排名，不以 0 補值。全部取消時明示需要至少一項，不凍結頁面。
- TO 使用既有反向 PR；FG% / FT% 使用原始百分比的 PR，沒有平均球員百分比來算團隊命中率。
- Rank 同時顯示 PR 合計，排序採完整精度。切換 AVG / TOT、期間或平台週次會使用相應 PR，並保持 Rank 排序跟隨可見期間。勾選球員比較區同步使用所選排名。

## 可選外觀微調

預設已排好，不需調整才能使用。「顯示設定」提供字級、列間距與賽程寬度微調及一鍵復原；設定只儲存在 `fantasyorgcat:table-display:v1`，不讀寫既有陣容。儲存被封鎖或額度不足時保留當次操作並明示無法儲存。排名項目新開頁面仍預設 9CAT。
