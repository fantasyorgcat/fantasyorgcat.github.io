# 全寬精簡賽程、六隊顯示與雙語／時區

基準 `9a0d2dc5e251de6bb68032c0e9d44738c2f24770`（PR #11）。版面參照 PR #9 的全寬球隊賽程，保留後續已完成的球員固定數據欄、勾選比較與自訂 PR 排名。

## 使用結果

- 球隊賽程恢復全寬，不套用球員表的賽程欄寬設定。日期欄依完整表寬排版，長期間／手機仍可橫向捲動。
- 每隊列高 80px，可視區計入表頭、六隊實際列高及原生捲軸；一次顯示六隊完整資料，保留固定表頭及場次排序。
- 賽事只顯示主客場隊名、原色塊、`#防守排名`、單一時區時間。完整防守來源與賽事狀態保留於 title，不再逐格重複「較難打、30隊、10/10、雙時區、未開賽」。
- 標語恢復「把下一場排入你的賽程」。頁首附近加入時區下拉與 English／繁體中文按鈕，首頁與配隊頁共用設定。
- 預設台北時間，可選美東、美西、東京、倫敦、UTC。日期與時間一起變更；球隊表、球員逐日賽程及勾選比較一致。
- 各平台計分週仍依原本經核對的美東日期界線選事件；時區只決定顯示日期欄與時間，不改場次、資料或 PR。跨日顯示可能比計分週多一個日期欄，保留完整賽事。
- 週次按鈕與選單操作保留；新開頁面預設 Yahoo 當期，開季前顯示最近的下一期。已驗證 2026-12-02 預設 Yahoo Week 7，沒有硬寫第一週。
- 中英文涵蓋導覽、表格與提示、排名設定、資料與缺值說明、配隊管理、動態訊息及雷達提示。切回中文可還原。使用者輸入的名稱及儲存紀錄不因語言切換改寫。
- 設定保存在獨立的 `fantasyorgcat:site-preferences:v1`；跨頁沿用。儲存受限時當次仍可切換，並明示未儲存。沒有外部翻譯請求或新增登入。
